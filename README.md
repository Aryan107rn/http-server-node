# HTTP Server — Node.js & Express

Learning and building HTTP servers from scratch using **Node.js** and **Express.js**.

## What I'm Learning

* HTTP basics: requests, responses, methods, headers & status codes
* Node.js `http` module
* Creating an HTTP server from scratch
* Routing & request handling
* Query & route parameters
* Request body & JSON
* Middleware
* REST APIs
* Express.js and how it simplifies Node's HTTP server

## Tech Stack

* Node.js
* Express.js
* JavaScript

## Goal

Understand how HTTP servers work internally and gradually move from a basic Node.js server to building APIs with Express.
